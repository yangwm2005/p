How to use Threadline

Write & organize

  • Type, then press Enter for a new item, Tab / Shift+Tab to indent or outdent
  • Click a bullet to zoom into it like a folder; click the ▸ arrow to collapse it
  • Drag a bullet to reorder items, or drag a document onto a folder in the sidebar to file it
  • Use the Lines button (top right) to show or hide the connector lines between bullets
  • Use the Tree button (top right) to view the outline as a diagram. Double-click text to edit, ✕ to delete, + to add a child, Enter to add a new item right below it. Use the small ⑃ Full branch / ▾ Below item button at the top of Tree view to switch layouts — click it to toggle back and forth. "Full branch" shows the whole tree at once as a horizontal branching diagram — like the classic Mac Tree app — with a resizable, renamable column per depth level (drag the handle on the right edge of a level's ruler band to resize it, double-click it to auto-fit, click the label to rename it). "Below item" instead expands children indented directly under an item, one branch open at a time. In Full branch, each item with children shows a small ⑃/▾/▸ icon in place of the bullet's expand arrow — click it (or the bullet) to cycle that item's subitems through fanning out as branches, nesting below it, and collapsing — mix all three freely in the same tree, and it works recursively: a sub-item nested "below" a branch item can itself be toggled back to fanning out its own branches

Checkboxes, bold & highlights

  • Open an item's ⋮ menu to mark it done, bold it, add a checkbox, or highlight it
  • Select some text within an item to pop up a small toolbar for bolding, italicizing, or highlighting just that selection
  • Turn a checkbox on and the next new item you create inherits it automatically

Find things

  • Use the search box at the top — toggle Doc / All to search just this document or every document
  • Type #tag or @tag anywhere in a bullet to tag it — an autocomplete list of your existing tags appears as you type. Click any tag to see every bullet that shares it, with its location shown as a breadcrumb
  • Hover a bullet and click the calendar icon to give it a date. Open the Calendar button (top right) to browse dated items by month, toggle between this document and all documents, and export them as an .ics file
  • Sort the document list in the sidebar by Updated, Created, Name, or Week — Week groups documents into "This Week", "Last Week", etc. based on when each was last updated (folders are set aside in this view)

Select multiple & bulk edit

  • Shift-click or Ctrl/Cmd-click bullets, or click-drag across empty space, to select several items at once
  • Open the ⋮ menu on any selected item to mark done, bold, toggle checkboxes, highlight, or delete the whole selection together

Share, print & export

  • Use Share / Export (top right) to invite others, print the full document, just what's currently open/closed, or just your current selection, copy the whole document, or export as .json / .txt

On phone & tablet

  • Tap the ☰ icon top-left to open your document list; tap outside it or pick a document to close it

Keyboard shortcuts

Enter new item   Shift+Enter line break
Tab indent   Shift+Tab outdent
↑↓ move focus   Alt+↑Alt+↓ reorder item
Ctrl+Enter toggle done   Ctrl+B toggle bold
Backspace at start merges with the line above
Ctrl+Z undo   Ctrl+Shift+Z redo
Select items, then Ctrl+C / Ctrl+X / Ctrl+V to copy, cut, paste
