✅ Adding & editing tasks

  • Click + Add task (top bar or bottom of the sidebar) to create a new task.
  • Click a task's name in the sidebar, or click its bar on the timeline, to open its detail panel — both do the same thing.
  • In the panel you can rename the task, set start/end dates with the Year/Month/Day dropdowns, pick a custom color for its bar, and see its Think Log.
  • A task's color overrides the default blue/light-blue coloring; the overdue indicator still shows as a red outline around a custom-colored bar rather than replacing your chosen color.
  • Use + Sibling to add a task at the same level, or + Sub-task to nest one underneath — the parent auto-expands.
  • Click 📝 Outliner in the top bar for a fast, all-in-one editing window: every task name in one indented list. Press Enter for a new task, Tab / Shift+Tab to indent/outdent, ↑/↓ to move between rows, and Backspace on an empty row to delete it (only if it has no sub-tasks, as a safety guard). Everything you type updates the main chart live.
  • In the Outliner, click the ▾/▸ caret to collapse or expand a task's sub-tasks (shared with the main sidebar — collapsing one collapses the other too), and drag the ⠿ handle to reorder or nest tasks, same drop zones as the main sidebar's drag handle.
  • Delete removes the task (and warns you first if it has sub-tasks, since those go with it).

📊 Timeline & dragging

  • Drag the middle of a bar sideways to move its dates; drag the edges to resize it.
  • Toggle Auto-size parent bars (top bar) to make any task with sub-tasks automatically span from its earliest sub-task's start to its latest sub-task's end — including sub-tasks nested several levels deep. While this is on, a parent's own dates become read-only (shown with a diagonal-stripe pattern on its bar) since they're calculated, not set directly — edit a sub-task's dates instead, and the parent updates automatically. You can still reorder or nest a locked parent by dragging it vertically, just not stretch its dates.
  • Drag a bar vertically (or drag the ⠿ handle in the sidebar) to reorder tasks — drop on the top/bottom of another row to become its sibling, or in the middle to nest as its sub-task.
  • With a task's panel open, press Tab to nest it under the task just above it, or Shift+Tab to move it back up a level — a quick keyboard alternative to dragging.
  • Click the ▾ / ▸ caret next to a task to collapse or expand its sub-tasks.
  • Day / Week buttons in the top bar jump between two zoom presets.
  • For finer control, click and drag left/right anywhere on the ruler (the row with the month and day labels) to continuously zoom in or out — your preferred scale is remembered separately for Day and Week mode.
  • Today scrolls the view back to the current date, marked with a dashed amber line.

🔗 Dependencies

  • Each task has a small number next to it in the sidebar — that's its row number, shown for every task in the project, including sub-tasks under any parent.
  • Open a task's panel and type the row numbers of tasks it depends on in the Predecessors field (e.g. 1, 3) — this works between any two tasks, whether they're under the same parent or under completely different top-level tasks.
  • An arrow is drawn from the end of each predecessor to the start of the dependent task — it turns red if the dates actually overlap.
  • Toggle Auto-shift dependents (top bar) to have a task automatically move later when its predecessor's dates change.
  • Toggle Auto-size parent bars (top bar) to make any task with sub-tasks automatically span from its earliest sub-task's start to its latest sub-task's end — like a summary bar in other Gantt tools. While it's on, a parent's own dates become read-only (shown with a diagonal stripe pattern on its bar) since they're calculated, not set directly; edit a sub-task's dates instead and the parent updates automatically, including through multiple levels of nesting.

📁 Projects

  • The project name in the top bar is a picker — click it to switch between projects, create a new one, or rename/delete an existing one.
  • Each project has its own completely separate set of tasks.

📥 Importing

  • Import loads a previously exported JSON file, replacing the tasks in your current project.
  • Import Outline reads an indented .txt file — indentation (spaces, tabs, bullets, numbering) becomes the task hierarchy — and always creates a new project so nothing existing gets overwritten.
  • 📋 Paste Outline does the same thing as Import Outline, but from your clipboard instead of a file — opens a box where you paste (Ctrl/Cmd+V) an outline and give the new project a name, no need to save a file first.
  • For a quicker one-off addition, you can also just paste (Ctrl/Cmd+V) an indented outline directly anywhere in the app (as long as you're not focused in a text field) and it's added straight into your current project as tasks and sub-tasks, without opening any dialog. Dates are just placeholders — drag them into place afterward.
  • Import Calendar reads a .ics calendar file (from Google Calendar, iCloud, Outlook, or Gantt's own export) and turns each event into a task in a new project — see Calendar import/export below for details.

🖨 Export & Print

  • Export downloads your current project's tasks as a JSON file — useful as a backup or to move a project between browsers.
  • Print opens a separate preview window with a clean, paper-friendly version of the chart — task names right on the bars, a month/day (or week) grid, and dependency lines. It has its own Print button so your main chart is untouched.
  • The printed view reflects whichever Day/Week zoom you currently have selected, and always fits tightly to your actual task dates (no empty padding).
  • Check 🩶 Row banding to shade every other task row light gray, making it easier to trace a row across a wide printed chart.
  • Check ⬜ Grayscale bars to print every bar in a neutral light gray instead of your task colors — useful for a black & white printer, or a more subdued, formal-looking printout. Combine it with Toner-saving for gray outlines instead of gray fills.
  • Check 🖨 Toner-saving in the preview window to switch bars from solid fills to colored outlines and drop the weekend shading — the same task colors and distinctions stay visible, just using far less ink/toner on paper.
  • Both options can be used together or separately, and update the preview instantly so you can see exactly what you'll get before printing.

📅 Calendar import/export

  • Calendar (export) downloads your current project as a standard .ics file — one calendar event per task, spanning its start-to-end dates. Import it into Google Calendar (Settings → Import & export), Apple/iCloud Calendar (File → Import), or Outlook (File → Open & Export → Import/Export).
  • Each event's description includes its dependencies ("Depends on: …") and parent task ("Part of: …") as readable text.
  • This is a one-time snapshot, not a live sync — editing a task afterward won't update the calendar event, and vice versa. Re-export and re-import whenever you want an updated copy.
  • Import Calendar reads any .ics file back in as a new project. Timed events become single-day tasks (the time itself isn't kept, since this app only tracks whole days); all-day events keep their full date range.
  • If you re-import a file this app exported, it recovers the actual dependencies and sub-task hierarchy from those "Depends on:" / "Part of:" lines — not just flat task names. Calendars from other sources won't have that, so they come in as a flat list, which is normal.
  • Recurring events (e.g. a weekly standup) only import as a single task for their first occurrence — the recurrence itself isn't expanded into repeated tasks.

☁ Cloud sync

  • Click Sign in (top right) to sync your projects with your Google account — the sync dot next to it shows the current status (green = synced, amber = saving, red = an error occurred).
  • Everything also works fully offline in this same browser — signing in adds cross-device sync on top, it doesn't replace local storage.

💬 Think Log

  • Every task has its own Think Log — open a task's panel and click 💬 Think Log to jot down timestamped notes, decisions, or reminders.
  • A preview of the log also appears directly in the task panel, so you don't need to reopen it just to check what's there.
  • Use + Section to drop in a labeled divider (Decision, Problem, Idea, etc.), or Export .txt to save the whole log for that task.

🔀 Q·PM integration

  • If you opened this chart via a "📊 Gantt Plan" link from Q·PM, the two are linked — you'll see a 🔗 Linked to Q·PM badge next to the project name, with a link back.
  • Tasks you add here show up in Q·PM, and vice versa — each app owns different fields (Gantt owns dates/hierarchy/dependencies, Q·PM owns status/priority/notes), so nothing gets overwritten by the other.
  • This requires being signed in with the same Google account in both apps, since that's the bridge between them.
